# ボカる！ / VOCALU

iPhone Safari向けの静的TCGです。5パックを開封し、25枚から20枚デッキを組み、CPUと対戦できます。カードは楽曲240種、ボカロP20種、歌い手40種の合計300種です。

- オリジナルブースター `BC01` をスワイプまたはタップして開封できます。
- 対戦中は右上の設定からBGM音量、軽量モード、リタイアを操作できます。

## v3データ移行

- 同一楽曲の通常版とコレクター版を1種類へ統合しました。
- 旧コレクター版の所持数は対応する通常カードへ一度だけ加算します。
- 移行前データはブラウザ内の `vocalu-save-v1-backup-v3` に保持します。
- 旧IDを含む保存デッキも新IDへ置換します。

## 逆転ルール

- 対戦はライフ5で開始します。
- 初期手札は好きな枚数を戻して同数を引き直すマリガンを1回だけ行えます。
- 攻撃した楽曲はRESTになり、次の自分のターンまで実効パワーが1000下がります。
- REST中の楽曲はガードできません。別のACTIVE楽曲はREST楽曲やライフをガードできます。
- ライフが2以下のプレイヤーは、召喚した楽曲でそのターンから攻撃できます。
- ライフからボカロPまたは歌い手がめくれると、そのカードのTRIGGERが自動発動します。
- TRIGGER効果は「相手の場を全破壊」「合計コスト10以下まで破壊」「最高パワーを手札へ戻す」「残りの攻撃を止める」の4系統です。
- ライフからめくれたカードは、効果の解決後に捨て札へ送られます。

## CPU難易度

- ノーマル：低コスト中心の気軽な対戦
- ハード：強いカードと倒しやすい対象を優先
- エキスパート：高い戦力と有利なカード交換を優先

## ローカル起動

```sh
python3 -m http.server 3345
```

`http://localhost:3345/` を開きます。`?test=1` でレア演出・盤面・装備確認用の開発者モードになります。

## データ方針

- 公式MV画像と再生数は、公式URL・確認日を伴うデータだけを表示します。
- 未確認カードは別楽曲の画像で代用しません。
- 現在の楽曲パワーはゲーム操作検証用のバランス値です。公開前に確認済み再生数データへ置き換えます。
- BGMはYouTube IFrame APIで指定プレイリストを再生し、音声抽出は行いません。
